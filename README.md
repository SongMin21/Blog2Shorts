# Blog2Shorts

블로그 콘텐츠를 **30~60초 9:16 숏폼 영상**으로 전환하는 웹서비스 MVP.

> (주)스마트동스쿨 기업실무체험 과제 — "블로그 콘텐츠를 활용한 생성형 AI 기반 숏폼 영상 제작 웹서비스 개발"

## 핵심 흐름

```
블로그 URL/본문 입력 → 대본 생성(Hook·본문·CTA) → 장면 구성·편집(4~6개)
→ TTS·자막 생성 → 9:16 영상 합성 → 미리보기·다운로드
```

## 필수 구현 기능

- [ ] 블로그 URL 또는 본문 입력
- [ ] 30~60초 분량의 숏폼 대본 생성
- [ ] 대본을 4~6개 장면으로 분할, 블로그 첨부 이미지 우선 활용
- [ ] 장면별 문구 및 이미지 수정
- [ ] TTS 음성 및 자막 생성
- [ ] 9:16 영상 합성
- [ ] 영상 미리보기 및 다운로드

## 추가 구현 가능 기능 (필수 흐름 완성 후)

- [ ] 장면별 AI 이미지 생성·재생성
- [ ] 음성 종류 선택
- [ ] 배경음악 적용
- [ ] 작업 내역 저장

## 기술 스택

| 영역 | 선택 |
|---|---|
| 프론트엔드 | React (배포: Vercel) |
| 백엔드 | Spring Boot — Java 17, 3.1.x |
| 생성형 AI / TTS | OpenAI API |
| 영상 합성 | 서버 사이드 렌더링 (9:16 mp4) |

## 현재 진행 상황

PRD 7번의 "오늘 만들 첫 화면" — **입력 화면** 시안을 `index.html`로 구현했다.
스마트동스쿨 브랜드 톤(메인 `#FE733B`, 흰 배경, Noto Sans KR)에 맞췄고,
PRD 4번에 정의한 세 가지 상태(기본·로딩·오류)를 화면 하단 전환 버튼으로 확인할 수 있다.
아직 서버 연동 전이라 동작은 화면 전환까지만 재현된다.

## 로컬에서 보기

```bash
python -m http.server 8777
```

`http://127.0.0.1:8777` 로 접속한다. 별도 빌드 과정은 없다.

## 배포 (Vercel)

저장소를 Vercel에 연결하면 루트의 `index.html`이 정적 사이트로 그대로 배포된다.
프레임워크 프리셋은 **Other**, 빌드 명령과 출력 디렉터리는 비워 둔다.

> 백엔드(Spring Boot)와 영상 합성 서버는 Vercel에 올릴 수 없다.
> 배포 위치는 PRD 8번 질문으로 기업에 확인이 필요하다.
